# ORM features on top of v0.1.0-test10

One page per feature. Each page says what changes for players, the switches (exact names, the kit's shipped value and the code's default), how it works and where it hooks into upstream files, the messages it uses, its tests, the log lines that tell which path ran, its status and its known gaps.

Every switch is an environment variable, set from the kit's `tools/release/kit/coop-options.ini`. ORM on/off switches take `1`, `true`, `yes`, `on` and `0`, `false`, `no`, `off` (any case); any other value keeps the default and logs one line (see [01-platform](01-platform.md)). Where a part has not been seen working in a game yet, it ships off.

Status words: **confirmed in game** means seen with two players in a real game run of the named harness scenario. **Not yet** means unit-tested only. Most runs were on our build based on test9; the ones marked "test10" ran on this tree.
