# ORM shared talk flags (LICHII_COOP_TALK=shared_talk.txt; D-R12, one world for everyone).
# What a talk changes in the world is the same in every game: a Kokiri who lets you pass, a
# Kokiri who moved, a deal done once, a quest step the townspeople refer to.
# What a talk changes for the one who talked stays his own: "already talked once" greetings
# (HaveTalked_*), the steps through a conversation (Talk_01, FirstTalk...), tutorials, Navi's
# hints, counters of who congratulated you. Not listed here, so not shared.
#
# One flag a line, then its rule (coop/host/flag_defer.hpp): a value another player's talk
# set waits while our player could see the change, and is written once
#   - our scene changed or is none of the line's scene: prefixes,
#   - none of the line's actor: prefixes is loaded, or every one is a copy another game
#     moves (its owner already shows the change),
#   - every one of them is farther than far: metres from our Link,
#   - or after: seconds went by (0: no time limit, wait for one of the others).
# "now" alone: shared and never held. Each line ends with the flag's hash as a comment
# (flag_hash of the name; the tests recompute it). Names and hashes from the RomFS's event
# flows and actor packs (oot-remake/docs/BANDERAS_CHARLA.md); nothing of the game is here.
