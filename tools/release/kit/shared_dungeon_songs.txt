# ORM songs (oot-remake docs/CANCIONES.md): the world flags the songs set that no other list
# shares yet. Made from coop/host songs.cpp's song_effects(); tests/host/songs_test.cpp checks
# this file says the same. A dungeon list file (coop/host dungeon_lists.hpp): load it after the
# others with LICHII_COOP_DUNGEON_LISTS=shared_dungeon_child.txt,shared_dungeon_adult.txt,
# shared_dungeon_songs.txt. NOT a LICHII_COOP_FLAGS file (it would take "once:" for a name).
#
#   once:Name         set for good: a 1 is never undone by another game's 0 or by a load
#   Name              shared both ways, live
#   hold:Name Place   a room gimmick's played event: shared, held while our Link is in Place
#   key64:0x...       a placement's one-time key (a 1 crosses, a 0 never undoes it)
#   toggle64:0x... Place  a key that goes both ways: shared, held while our Link is in Place
#
# Names checked against GameData/GameDataList (Bool, ResetTypeValue 8); the keys are the
# Obj_SongOfTimeSign_A_01 placements with isSaveGameData in the Banc files (isOnceOnly: key64;
# the blocks that swap back and forth: toggle64, docs/RIESGOS_RESUELTOS.md "Mundo e historia").
