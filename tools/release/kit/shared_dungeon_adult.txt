# ORM, the adult part of the game (oot-remake docs/CONTENIDO_ADULTO.md): what the built-in
# dungeon list (lichii/hook/coop_dungeon.cpp) shares that it should not, and the adult
# overworld state no list shares yet. A dungeon list file (coop/host dungeon_lists.hpp):
# load it after the built-in list with LICHII_COOP_DUNGEON_LISTS=shared_dungeon_child.txt,
# shared_dungeon_adult.txt. NOT a LICHII_COOP_FLAGS file: that reader would take the
# "unshare:" and "held:" lines for flag names.
#
#   SomeFlag                   shared (any line of the shared flags file syntax)
#   once:SomeFlag              shared by the pickup rule (a 1 is never undone by a 0)
#   unshare:SomeFlag           taken off the shared list
#   held:SomeFlag Scene        a held switch: taken off, left to the held-switch rules
#
# Read from the romfs (Logic/*.ainb, AI/*.ainb, Event/EventFlow; names checked against
# GameData/GameDataList, Bool or Int, ResetTypeValue 8). Checked in
# tests/lichii/adult_list_test.cpp: every unshare: and held: line is in the built-in list,
# no shared or once: line is.
