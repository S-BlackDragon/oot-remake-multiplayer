# ORM bottles and trade chains with several players (oot-remake docs/BOTELLAS_TRUEQUES.md).
# Written by oot-remake/tools/romfs/trade_list.py from the romfs (names checked against
# GameData/GameDataList: once: a saved Bool, plain lines a saved Bool or Int, enum: values in
# the game's order, unshare: a trade item's StockNum); edit the table there, not this file.
# A dungeon list file (coop/host dungeon_lists.hpp), loaded with LICHII_COOP_DUNGEON_LISTS
# after the child, adult and minigame lists. NOT a LICHII_COOP_FLAGS file.
#
# The rule (oot-64: one save for the group, D-035, D-061, D-072.12): a bottle is the group's,
# what is in it is each player's (a new bottle reaches the others empty); what is handed out
# once is handed out once for the group; a trade chain is one chain for the group; the timers
# are each player's. Not here on purpose: GetSwordBigGoron_ElapsedTime and
# HyruleCastle_StopWeirdEggHatchTimer (each game's clock), the Zora shop's fish and the cows'
# milk (they can be had again), GhostShop_CouponNum_ForMessage (not saved), the bottle
# tutorial's run, IsGet.Item_Bottle_BigPoe (the Poe talk's first time), the handovers' talks
# (CancelHandover*, IsAfterShow*, TalkedAfter_EggHatched: the talk list's), Cojiro and the Odd
# Powder (no timer: they stay mirror), the red ice (shared_dungeon_towns.txt).

# ---- Bottles handed out once for the group. Owning a bottle is shared (items list:
# PouchData.Bottle<X>.StockNum, BottleInfo.Bottle<X>.IsValid); what is in it never is (BottleItem,
# each player's). The Market potion shop's bottle (the insect tutorial of Npc_Hylia_020): its run
# (Step_Market_Item_Bottle_TutorialEvent, _Started, the insects) stays the player's
once:Npc_Hylia_020_Shop_Item_Bottle_Present    # the shop's bottle was given: no second one
once:Market_Item_Bottle_TutorialEvent_Cleared    # the tutorial was cleared: it is not offered again

# ---- Ruto's letter: one letter for the group. It goes into the finder's bottle (its content is
# his); the other games get the new bottle empty and no second letter in the lake (the same line as
# shared_dungeon_towns.txt). King Zora moving is the story's (Step_Get_StoneOfWater, ShowLetter)
once:IsGet.Item_Bottle_Letter    # the letter was taken: gone from every lake
once:Get_StoneOfWater_GetRutoLetter    # Ruto's letter found: its bottle is gone from the lake
