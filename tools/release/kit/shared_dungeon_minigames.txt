# ORM minigames and side activities with several players (oot-remake docs/MINIJUEGOS.md).
# Written by oot-remake/tools/romfs/minigame_list.py from the romfs (names checked against
# GameData/GameDataList: once: a saved Bool, plain lines a saved Bool or Int, enum: values in
# the game's order); edit the table there, not this file. A dungeon list file (coop/host
# dungeon_lists.hpp), loaded with LICHII_COOP_DUNGEON_LISTS after shared_dungeon_child.txt and
# shared_dungeon_adult.txt. NOT a LICHII_COOP_FLAGS file (that reader takes once: for a name).
#
# The rule (oot-64: one save for the group, D-061): whoever plays a minigame plays it in his
# own game, with his own timer, score, record, rented items and paying; what a minigame hands
# out once is handed out once for the group. The flag that says "the prize was given" is
# shared one way (once:): a second player who wins gets what the game gives after the prize
# (rupees), as a one-player game does the second time. Not here on purpose: records and best
# times (MiniGame_*_BestScore, _BestTime_*, _Record*), the run state (Step_MiniGame_* Playing,
# _Progress, timers), tutorials and talks, Ingo's race (LonLonRanch_GambleRace*: each his own;
# Epona is D-R19's), Malon's obstacle course (no prize flag), the fishing pond (its prizes are
# the items list's, issue 151) and the House of Skulltula (shared_dungeon_adult.txt).
