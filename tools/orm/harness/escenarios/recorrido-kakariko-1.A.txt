# recorrido-kakariko-1 (ORM, docs/RECORRIDOS.md, bloque 6. Kakariko y Cementerio), A: tramo 1, Kakariko hasta el Cementerio.
# KakarikoVillage_Child: warp to KakarikoVillage_Entrance, then room by room with place/goto; see recorrido-kakariko.steps.txt.
# Run alone: r03_pareja.py --scenario recorrido-kakariko-1 --transport ws (switches from the header).
#! noload
#! start coop: test warp done
#! saves 06-kakariko
#! switches LICHII_COOP_PUPPET=1,LICHII_COOP_DEBUG_OBJECTS=1,LICHII_COOP_DEBUG_FLAGS=1,LICHII_COOP_DEBUG_BOSS=1,LICHII_COOP_STORY=1,LICHII_COOP_DUNGEON_LISTS=shared_dungeon_child.txt
#! timeout 900
#! expect A coop: test warp done
#! never A coop: test goto timed out
#! never A coop: test place .*: failed
#! expect A coop: puppet: P\d:? (create )?CoopPuppet_Child within llegada..r01-entrada
#! never A (?<!fairy )coop: puppet: P\d show -> hide within r01-entrada..salida
#! expect A coop: lists: .*shared_dungeon_child\.txt: \d+ flags and keys added within boot..
#! expect A coop: test place \-119\.77 96\.93 58\.70: done within r01-entrada..r02-molino
#! expect A coop: test place \-10\.11 104\.93 43\.34: done within r02-molino..r03-puerta-montana
#! expect A coop: test flag KakarikoVillage_Windmill_DoorOpened \(0xc7fe3216\) = 1 within r02-molino..r03-puerta-montana
#! expect A coop: test place \-41\.20 110\.29 \-10\.00: done within r03-puerta-montana..r04-cementerio
#! expect A coop: test flag HavePlayedEvent\.KakarikoVillage_ClosedGateOpen \(0xf8823cf0\) = 1 within r03-puerta-montana..r04-cementerio
#! expect A coop: test place \-5\.73 101\.84 68\.80: done within r04-cementerio..salida
#! expect A coop: drops: asked for the drops of Graveyard within salida..fin
#! expect A coop: puppet: P\d:? (create )?CoopPuppet_Child within salida..fin
mark start
warp KakarikoVillage_Child KakarikoVillage_Entrance
wait 1200               # the title screen
mark title
press A
wait 180
press A
wait 180
press A
wait 300
press A                 # loads the save, then the warp
wait 2400               # the save loads, then the warp lands (about 30 s)
mark llegada
wait 3000               # B loads after A (r03_pareja) or with it (run.ps1): wait for it
mark r01-entrada            # la entrada desde el campo
place -119.77 96.93 58.70
wait 120
goto -105.00 55.00 1.5 900
wait 300                # the other one sees us in this room
mark r02-molino            # el molino
place -10.11 104.93 43.34
wait 120
goto -20.00 40.00 1.5 900
flag KakarikoVillage_Windmill_DoorOpened 1
wait 60
wait 300                # the other one sees us in this room
mark r03-puerta-montana            # la puerta de la Montaña (guardia, carta de Zelda)
place -41.20 110.29 -10.00
wait 120
goto -41.20 -10.00 1.5 900
flag HavePlayedEvent.KakarikoVillage_ClosedGateOpen 1
wait 60
wait 300                # the other one sees us in this room
mark r04-cementerio            # el camino del Cementerio
place -5.73 101.84 68.80
wait 120
goto 5.00 66.00 1.5 900
wait 300                # the other one sees us in this room
mark salida             # al Cementerio
goto 16.72 64.14 0.8 900
wait 1800               # the scene change, then the other one lands too
mark fin
