# meca-agua-templo (A): the Water Temple's three levels for everyone. Both adult at the entrance from Lake Hylia.
# A plays the three triforce events (the game's own SageOfWater/WaterTemple_WaterLevelChange0N: each plays
# Dm_WaterTemple_0020/0021/0022 and writes the level Int 0, 1, 2 and the one-hot Bools). B: the Int arrives (at
# once, or after its wait while B's Link swims), B's one-hot Bools follow it (derived, not shared), and the gimmick
# probe says whether B's loaded water planes moved (the live question of AGUA.md, section 5).
# Mutant: without LICHII_COOP_WATER the B 'water:' lines go red (the Int still crosses: daurosk shares it).

#! expect A coop: flags debug: int 0xbeb09982 \(entry \d+\) 2 -> 0 within low..mid
#! expect B coop: flags debug: int 0xbeb09982 \(entry \d+\) 2 -> 0 within low..mid
#! expect B coop: water: WaterTemple_Room00_WaterLevel (2 -> 0 \(P\d\): written in WaterTemple, live|.*waited [0-9.]+ s: written) within low..mid
#! expect B coop: water: WaterTemple_Room00_WaterLevel is 0: WaterTemple_WaterLevelChange01 1 within low..mid

#! expect B coop: water: WaterTemple_Room00_WaterLevel is 2: WaterTemple_WaterLevelChange02 0, WaterTemple_WaterLevelChange03 1 within high..end
#! expect B coop: gimmick probe: .*WaterPlane.* words stepped within low..end

#! expect B coop: water: WaterTemple_Room00_WaterLevel: (live: (a water plane moved|the water planes changed)|not live: no water plane moved) within low..end
#! never B coop: water: WaterTemple_Room00_WaterLevel: live unknown
