# mini-zora (A: sets the flags as the game's setter; the checks of B are in B's file): the frogs and the diving game: the Song of Storms prize, the all-songs heart piece and the Silver Scale game are given once for the group; a game being played stays its player's.
# docs/MINIJUEGOS.md (the minigame list, tools/release/kit/shared_dungeon_minigames.txt).
# Run with --transport ws and --env for each of LICHII_COOP_PUPPET=1,LICHII_COOP_DEBUG_FLAGS=1,LICHII_COOP_DUNGEON_LISTS=shared_dungeon_minigames.txt (r03_pareja; run.ps1 reads #! switches);
# the list files next to the emulator, as the kit puts them. Mutant: the same run without
# LICHII_COOP_DUNGEON_LISTS turns B's expect lines of a prize red (no list shares it).
#! noload
#! start coop: test warp done
#! switches LICHII_COOP_PUPPET=1,LICHII_COOP_DEBUG_FLAGS=1,LICHII_COOP_DUNGEON_LISTS=shared_dungeon_minigames.txt
#! expect A coop: lists: .*shared_dungeon_minigames\.txt: 30 flags and keys added, 0 taken off, 28 once, 0 held in their area, 0 one-time keys within boot..
#! expect A coop: test flag MiniGame_FrogTenors_StormSong \(0xd578df95\) = 1: queued
#! expect A coop: test flag MiniGame_FrogTenors_SongClear \(0xc69d8bbf\) = 1: queued
#! expect A coop: test flag MiniGame_Diving_Cleared \(0x697507aa\) = 1: queued
#! expect A coop: test flag MiniGame_FrogTenors_Playing \(0x16451868\) = 1: queued
#! expect A coop: test flag MiniGame_Diving_Playing \(0x21f90ccd\) = 1: queued
mark start
warp ZoraRiver_Child ZoraRiver_FromZoraDomain
wait 1200               # the title screen
mark title
press A
wait 180
press A
wait 180
press A
wait 300
press A                 # loads the save, then the warp
wait 2400               # the save loads, then the warp lands (about 30 s)
mark after
wait 600                # the other game lands too: puppets made
mark control
flag MiniGame_FrogTenors_StormSong 1          # a prize given: one for the group
flag MiniGame_FrogTenors_SongClear 1          # a prize given: one for the group
flag MiniGame_Diving_Cleared 1          # a prize given: one for the group
flag MiniGame_FrogTenors_Playing 1          # this player's own: never crosses
flag MiniGame_Diving_Playing 1          # this player's own: never crosses
wait 600
wait 300
mark end
