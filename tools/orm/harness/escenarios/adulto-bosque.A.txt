# adulto-bosque (ORM, docs/CONTENIDO_ADULTO.md, block 12, Templo del Bosque), A: both adult at the Forest Temple's entrance. A sets Meg's fight start (ForestTemple_MegBattleStart, an area Link walks into: taken off by the adult list), then the ivy of room 08 (ForestTemple_Room08_ClimbIvy, room state, shared by the built-in list): B never gets the first and gets the second live.
# Run with --transport ws --env LICHII_COOP_PUPPET=1 --env LICHII_COOP_DEBUG_FLAGS=1
# --env LICHII_COOP_DUNGEON_LISTS=shared_dungeon_adult.txt (the adult branch's kit file, next to the emulator as
# shared_story.txt is; its reader comes with the child-dungeon branch). Mutant: the same run without
# LICHII_COOP_DUNGEON_LISTS turns the 'never' lines red (the built-in list still shares those flags) and the
# lines of a flag only the adult list shares.
#! noload
#! start coop: test warp done
#! saves 12-bosque
#! switches LICHII_COOP_PUPPET=1,LICHII_COOP_DEBUG_FLAGS=1,LICHII_COOP_DUNGEON_LISTS=shared_dungeon_adult.txt
#! expect B coop: puppet: P\d: create CoopPuppet_Adult

#! expect A coop: test flag ForestTemple_Room08_ClimbIvy \(0x8f8af32e\) = 1 within control..end
#! expect B coop: flags debug: bool 0x8f8af32e \(entry \d+\) 0 -> 1 within control..end
#! never B coop: flags debug: bool 0x5a52cb64
