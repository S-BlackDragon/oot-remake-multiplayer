# epona-carrera (ORM D-R19, docs/EPONA.md), A: our own race holds the group's Epona. A's race with Ingo runs
# (Step_Get_Epona GambleRacePlaying, set by the test command); B wins meanwhile (NotReady -> Complete); A must
# hold B's Complete while racing ('came during our race: it waits'), then lose (ReadyForGambleRace) and only then
# take Complete. Without the hold Complete lands under A's running race, and A's loss puts him back to
# ReadyForGambleRace for good. Run with --transport ws --env LICHII_COOP_PUPPET=1 --env LICHII_COOP_DEBUG_FLAGS=1.
# Mutant: drop the hold (the hook's `epona_race` check): the 'it waits' line goes red. By hand: A's last
# 'test enum Step_Get_Epona' (mark after-race) reads value 0x4c0a63f4 (Complete), not ReadyForGambleRace.
# Precondition: neither save has Epona yet (each log's first 'coop: epona: Step_Get_Epona here is' line is not
# Complete): a group that has her already never sends her again, so such a run proves nothing; give the
# games saves from before Lon Lon (save_flags.py, E15) and say so in the run's notes.

#! expect A coop: epona: our race with Ingo is over: the group's Epona may come
