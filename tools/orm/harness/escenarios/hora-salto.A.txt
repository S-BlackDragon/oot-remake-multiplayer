# LICHII_COOP_CLOCK_TEST_OFF=-43000@120 instead (a quiet move, not a jump) turns A's jump lines red.

#! switches LICHII_COOP_PUPPET=1,LICHII_COOP_DEBUG_TIME=1

#! expect A coop: time: set to 00:0\d:\d\d within day..end
#! expect B coop: clock: in step with the shared clock within night..end
#! never A coop: clock: sent a jump within day..end
#! never B coop: clock: set to within day..end
