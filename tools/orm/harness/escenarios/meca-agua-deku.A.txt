# meca-agua-deku (A): the Deku Tree basement water drops for everyone (both child at the entrance).
# A queues room G's water flag (the one its placement group and GroundControl mover read). daurosk saw this
# room's water come live in a player test (2026-11-10): the same mover as the Water Temple's.
# Run with --transport ws; run.ps1 reads #! switches. Doc: docs/AGUA.md (PLAN_100 F6/E13).
#! noload
#! start coop: test warp done
#! switches LICHII_COOP_PUPPET=1,LICHII_COOP_DEBUG_FLAGS=1,LICHII_COOP_WATER=1,LICHII_COOP_GIMMICK_PROBE=1
#! timeout 400
#! expect B coop: flags debug: bool 0x392a228a \(entry \d+\) 0 -> 1 within set..end
#! expect B coop: water: InsideTheDekuTree_RoomG_WaterLevel_timing (0 -> 1 \(P\d\): written in InsideTheDekuTree, live|.*waited [0-9.]+ s: written) within set..end
#! expect B coop: gimmick probe: .*(WaterPlane|WaterGate).* words stepped within set..end
mark start
warp InsideTheDekuTree Entrance child
wait 1200               # the title screen
mark title
press A
wait 180
press A
wait 180
press A
wait 300
press A                 # loads the save, then the warp
wait 2400               # the save loads, then the warp lands (about 30 s)
mark after
wait 600                # the other game lands too
mark set
flag InsideTheDekuTree_RoomG_WaterLevel_timing 1
wait 30
flag InsideTheDekuTree_RoomG_WaterLevel_timing 1               # twice: a queued write may miss the frame
wait 1200
mark end
