# cartera-cada-uno (A): each player's own wallet, everyone's rupees on screen (player request, 2026-11-11
# docs/INVENTARIO.md, "Cartera de cada uno"; docs/TIPOS_MENSAJE.md, PLAYER_EQUIP component 29). Both land in the
# Market as children with the kit's item list (shared_items.txt: rupees per player) and the in-game HUD with its
# panel shown. A sets its wallet to 87, later spends down to 25; B sets its own to 43 (cartera-cada-uno.B.txt).
# Each game logs every wallet it knows ("coop: wallet: P1 'Ana' (you) has 87 rupees"): A sees B's 43 and keeps its
# own 87 / 25; B's 43 never lands in A's wallet. The screenshots at A's marks show the panel's wallet list (name in
# the player's colour, a green rupee, the count) under the panel lines (docs/VISUAL_CHECKLIST.md).
# Needs the hook from orm/cartera and shared_items.txt next to the emulator, as the kit puts it.
# Mutant: the same run with a list holding ZMP's common wallet ("count PlayerStatus.CurrentRupee" and its cap line
# back in shared_items.txt) turns the `never` lines red (B's 43 becomes a change of A's wallet).
# Run: python -I tools/orm/harness/r03_pareja.py --scenario cartera-cada-uno --scen-dir tools/orm/harness/escenarios
#   --transport ws --capture-marks. Not run yet (written 2026-11-11, no game that day). Player numbers vary: P\d.
