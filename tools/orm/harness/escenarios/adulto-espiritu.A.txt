# adulto-espiritu (ORM, docs/CONTENIDO_ADULTO.md, block 19, Templo del Espiritu (las dos mitades)), A: A ADULT and B CHILD in the Spirit Temple's entrance hall (the temple has a child half and an adult half): each sees the other's puppet at its own age. A sets the room 12 Iron Knuckle fight start (SpiritTemple_Room12_FightBegain, it shuts the room behind its player: taken off), then room 02 unlocked (SpiritTemple_Room02_Unlocked: shared). With the D-R17 age rule in, B may be reloaded adult: then A's CoopPuppet_Child line turns red, and that is the rule working, not a fault.
# Run with --transport ws --env LICHII_COOP_PUPPET=1 --env LICHII_COOP_DEBUG_FLAGS=1
# --env LICHII_COOP_DUNGEON_LISTS=shared_dungeon_adult.txt (the adult branch's kit file, next to the emulator as
# shared_story.txt is; its reader comes with the child-dungeon branch). Mutant: the same run without
# LICHII_COOP_DUNGEON_LISTS turns the 'never' lines red (the built-in list still shares those flags) and the
# lines of a flag only the adult list shares.
#! noload
#! start coop: test warp done
#! saves 19-espiritu-adulto
#! switches LICHII_COOP_PUPPET=1,LICHII_COOP_DEBUG_FLAGS=1,LICHII_COOP_DUNGEON_LISTS=shared_dungeon_adult.txt
#! expect B coop: puppet: P\d: create CoopPuppet_Adult
#! expect A coop: puppet: P\d: create CoopPuppet_Child
#! expect A coop: test flag SpiritTemple_Room12_FightBegain \(0x05fc38ec\) = 1 within sensor..end
#! expect A coop: test flag SpiritTemple_Room02_Unlocked \(0x6f951499\) = 1 within control..end
#! expect B coop: flags debug: bool 0x6f951499 \(entry \d+\) 0 -> 1 within control..end
#! never B coop: flags debug: bool 0x05fc38ec 
mark start
warp SpiritTemple SpiritTemple_Entrance adult
wait 1200               # the title screen
mark title
press A
wait 180
press A
wait 180
press A
wait 300
press A                 # loads the save, then the warp
wait 2400               # the save loads, then the warp lands (about 30 s)
mark after
wait 600                # the other game lands too: puppets made
mark sensor
flag SpiritTemple_Room12_FightBegain 1
wait 300
mark control
flag SpiritTemple_Room02_Unlocked 1
wait 600
wait 300
mark end
