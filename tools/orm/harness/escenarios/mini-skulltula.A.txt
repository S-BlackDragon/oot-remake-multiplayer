# mini-skulltula (A: sets the flags as the game's setter; the checks of B are in B's file): the House of Skulltula's 50-token heart piece (the adult list shares the five rewards) is taken once for the group; the reward talk stays A's.
# docs/MINIJUEGOS.md (the minigame list, tools/release/kit/shared_dungeon_minigames.txt).
# Run with --transport ws and --env for each of LICHII_COOP_PUPPET=1,LICHII_COOP_DEBUG_FLAGS=1,LICHII_COOP_DUNGEON_LISTS=shared_dungeon_adult.txt,shared_dungeon_minigames.txt (r03_pareja; run.ps1 reads #! switches);
# the list files next to the emulator, as the kit puts them. Mutant: the same run without
# LICHII_COOP_DUNGEON_LISTS turns B's expect lines of a prize red (no list shares it).
#! noload
#! start coop: test warp done
#! saves 12-bosque
# run.ps1 splits #! switches at every comma, so a list of files cannot be a value there: '.' is the
# emulator's folder (where the list files are), and the hook loads every shared_dungeon_*.txt in it.
#! switches LICHII_COOP_PUPPET=1,LICHII_COOP_DEBUG_FLAGS=1,LICHII_COOP_DUNGEON_LISTS=.
#! expect A coop: lists: .*shared_dungeon_minigames\.txt: \d+ flags and keys added within boot..
#! expect A coop: test flag KakarikoVillage_GatheringTokenGold_GetReward50 \(0xe3c6e4a3\) = 1: queued
#! expect A coop: test flag GatheringTokenGold_ContinuousRewardTalk \(0x281e53e4\) = 1: queued
mark start
warp KakarikoVillage_Adult Kakariko_WellSide
wait 1200               # the title screen
mark title
press A
wait 180
press A
wait 180
press A
wait 300
press A                 # loads the save, then the warp
wait 2400               # the save loads, then the warp lands (about 30 s)
mark after
wait 600                # the other game lands too: puppets made
mark control
flag KakarikoVillage_GatheringTokenGold_GetReward50 1          # a prize given: one for the group
flag GatheringTokenGold_ContinuousRewardTalk 1          # this player's own: never crosses
wait 600
wait 300
mark end
