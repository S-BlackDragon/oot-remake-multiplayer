# adulto-pozo (ORM, docs/CONTENIDO_ADULTO.md, block 16, Pozo (de nino)), A: both CHILD at the Bottom of the Well (a child dungeon: the last word asks the age). A sets the coffin room check (BottomOfTheWell_CoffinRoomCheck: taken off), then room 07's lock (BottomOfTheWell_Room07_UnLock: shared).
# Run with --transport ws --env LICHII_COOP_PUPPET=1 --env LICHII_COOP_DEBUG_FLAGS=1
# --env LICHII_COOP_DUNGEON_LISTS=shared_dungeon_adult.txt (the adult branch's kit file, next to the emulator as
# shared_story.txt is; its reader comes with the child-dungeon branch). Mutant: the same run without
# LICHII_COOP_DUNGEON_LISTS turns the 'never' lines red (the built-in list still shares those flags) and the
# lines of a flag only the adult list shares.
#! noload
#! start coop: test warp done
#! saves 16-pozo
#! switches LICHII_COOP_PUPPET=1,LICHII_COOP_DEBUG_FLAGS=1,LICHII_COOP_DUNGEON_LISTS=shared_dungeon_adult.txt
#! expect B coop: puppet: P\d: create CoopPuppet_Child
#! expect A coop: test flag BottomOfTheWell_CoffinRoomCheck \(0x0b5b3b0c\) = 1 within sensor..end
#! expect A coop: test flag BottomOfTheWell_Room07_UnLock \(0xb8daefc7\) = 1 within control..end
#! expect B coop: flags debug: bool 0xb8daefc7 \(entry \d+\) 0 -> 1 within control..end
#! never B coop: flags debug: bool 0x0b5b3b0c 
mark start
warp BottomOfTheWell Well_KakarikoSide child
wait 1200               # the title screen
mark title
press A
wait 180
press A
wait 180
press A
wait 300
press A                 # loads the save, then the warp
wait 2400               # the save loads, then the warp lands (about 30 s)
mark after
wait 600                # the other game lands too: puppets made
mark sensor
flag BottomOfTheWell_CoffinRoomCheck 1
wait 300
mark control
flag BottomOfTheWell_Room07_UnLock 1
wait 600
wait 300
mark end
